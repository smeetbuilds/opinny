# Contributing to Opinny

Opinny is an open-source frontend platform developed by Aahav Labs.

1. Create a focused branch.
2. Use Bun for dependency management.
3. Keep domain contracts backend-neutral.
4. Do not place provider-specific API calls inside UI components.
5. Run `bun run typecheck` and `bun run build` before opening a pull request.
6. Include screenshots for visual changes and explain responsive behavior.
